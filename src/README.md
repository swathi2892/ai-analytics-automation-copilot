# AI Analytics Automation & Copilot Reporting Briefs

An intelligent automation tool built in Python that monitors production metrics, flags yield variance anomalies, and automatically generates automated executive briefs.

---

## 📌 Business Impact
Automating routine data audit workflows reduces manual reporting overhead by hundreds of hours, accelerating decision-making when yield anomalies occur on the factory floor.

## 🛠️ Key Capabilities
* **Automated Anomaly Detection:** Real-time scanning for threshold breaches in production yields.
* **Executive Summary Engine:** Generates natural-language executive briefs outlining critical lot impacts.
* **Workflow Automation:** Replaces manual daily report generation with automated script execution.
